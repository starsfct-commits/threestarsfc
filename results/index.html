Connect to publish

Changes are saved straight to the website’s GitHub repository. You need a GitHub access token to publish. You only have to do this once on each phone or computer.

  1. Sign in to GitHub with an account that can edit starsfct-commits/threestarsfc.
  2. Open New fine-grained token.
  3. Name it Match centre and pick an expiry date. Under Repository access, choose Only select repositories, then threestarsfc.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it and paste it below.

The token is kept only in this browser. Anyone who has it can change the website, so don’t share it.
